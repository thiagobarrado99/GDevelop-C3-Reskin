# Construct 3 editor UI survey

Collected 2026-09-17 with Playwright against https://editor.construct.net/ (r495.2, guest, free edition), viewport 1600×900, locales `en-US` and `pt-BR`. Only structure and labels were recorded — no code, assets or icons. English first, pt-BR in *italics* where it differs. Use this as the source of truth for Phases 2–4.

## Shell

Top toolbar (left→right): `Menu` button · Save · Undo ▾ · Redo ▾ · Preview ▶ ▾ (*Visualizar*) · `Buy now` (red) · document tabs (Start page, Layout 1, Event sheet 1 — closable, active one cream/yellow) · right: `Free edition` chip (*Edição gratuita*) · `Guest` + avatar (*Visitante*).

Preview ▾ menu: Preview layout · Add another layout preview · Debug layout · Preview project · Add another project preview · Debug project · Remote preview · Main button. Free-edition chip popup: Register… · Log in · Purchase… · Enter access code · View details.

Docked bars (default layout): **Properties** left (full height, 315 px); **Project** top-right (315 px) with a search box; **Layers** bottom-right, tab strip under it `Layers - Layout 1 | Tilemap` (*Camadas - Layout 1 | Mosaico*); **Asset Browser** bottom-centre (*Navegador de Ativos*: Source select "Store free bundled assets / Store premium bundled assets / Store purchased assets / Local assets", up-folder, ⚙, search). Bar title = plain text, right side pin + ✕. Bar-title context: Undock · Pin · Open to popup window · Close. Tab context: Colors · Undock · Close · Close others.

Main menu (☰ `Menu`): Start page (*Página inicial*) · Project ▸ (*Projeto*) · Guided tours ▸ (*Tours guiados*) · View ▸ (*Exibir*) · Account ▸ (*Conta*) · Get addons (*Obter complementos*) · Asset Store (*Loja de Assets*) · Settings (*Configurações*) · Help (*Ajuda*) · About (*Sobre*).
- Project ▸: Save · Save as · Preview · Remote preview · Debug · Export · Close project · New · Open (*Salvar · Salvar como · Visualizar · Visualização remota · Depurar · Exportar · Fechar projeto · Novo · Abrir*).
- View ▸: Start page · Example browser · Addon manager · Export manager · Storage cleanup.

## Start page

Logo top-left. Two wide grey buttons `NEW` / `OPEN ▾` (*NOVO / ABRIR*) + `BROWSE EXAMPLES` (*EXPLORAR EXEMPLOS*). Left column `RECENT PROJECTS` (*PROJETOS RECENTES*) then `SOCIAL MEDIA`. Three card columns, uppercase small headers: LEARN (Beginner's guide, Manual, Tutorials) · PARTICIPATE (Arcade, Blogs, Forum) · EXPLORE (Asset store, What's new, construct.net) — flat grey cards, teal icon left, uppercase title + one-line description. Bottom: `RECOMMENDED EXAMPLES` (*EXEMPLOS RECOMENDADOS*) thumbnails with ★ title, description, ▶ button. Tooltips: "Click to create a new empty project." / "Click to open an existing project."

## New project dialog (*Novo projeto*)

Title bar with ✕. Label-left rows: Name (*Nome*, placeholder "New project") · Choose preset (*Escolha uma pré-definição*: Retro style, SD landscape 4:3, SD portrait 3:4, SD landscape 16:9 (default, 854×480), SD portrait 9:16, 720p/1080p/4K landscape+portrait) · Viewport size W × H + ratio label (*Tamanho da tela*) · Orientations Any/Portrait/Landscape (*Orientações: Qualquer uma/Retrato/Paisagem*) · Start with: Event sheet/JavaScript/TypeScript (*Começar em*) · ☐ Optimize for pixel art (*Otimizar para pixel art*). Footer: `Help` link left; `Create` `Cancel` right (*Ajuda / Criar / Cancelar*).

Defaults after Create: project "New project" (*Novo projeto*), "Layout 1", "Event sheet 1" (*Folha de eventos 1*), "Layer 0" (*Camada 0*), layout size 1708×960, margins 1000×1000, grid 32×32×32.

## Layout view

Canvas with the layout as a white/light rectangle, dashed margin outline, 2D/3D/eye floating toggle top-centre, status bar bottom-right `Mouse: (x, y)  Active layer: Layer 0  Zoom: 100%` (*Mouse · Camada ativa · Zoom*). Context menu (empty space): Insert new object · Timeline ▸ · View ▸ (Zoom in, Zoom out, Reset zoom, Set 3D view mode, Copy co-ordinates, Start/Stop all live previews) · Edit event sheet · Paste · Help. Instance context: Edit · Insert new object · Add ▸ · Z Order ▸ · Align ▸ · Lock ▸ · Mesh ▸ · View ▸ · Cut · Copy · Paste · Clone object type · Delete · Find all references… · Help (*Editar · Inserir novo objeto · Adicionar · Ordem Z · Alinhar · Bloquear · Malha · Visualizar · Recortar · Copiar · Colar · Clonar tipo de objeto · Excluir*). Double-click empty space = Insert new object.

**Create new object type** dialog (*Criar novo tipo de objeto*): "Choose a plugin to create a new object type from:" + search; tile grid grouped by category (3D · Data & storage · General (9-patch, Flowchart controller, Particles, Shadow light, Sprite, Sprite font, SVG Picture, Text, Tiled Background, Tilemap, Timeline controller) · HTML elements · Input (Gamepad, Keyboard, Mouse, Touch) · Media · Monetisation · Other · Platform specific · Web); Name field + one-line description under the grid; footer Help · Get addons left, Insert · Cancel right. Inserting a Sprite then clicking the layout opens the **Animations Editor** window.

**Animations Editor: Sprite** — window with title bar; left: Color palette + swatches, colour preview, RGBA fields; tool column: Rectangle select (S), Eraser (E), Pencil (N), Brush (B), Line (L), Rectangle (R), Ellipse (T), Fill (F), Eye dropper (I), Edit image points (⇧I), Edit collision polygon (⇧P); top toolbar: Clear image (C), Load images (Ctrl+O), Save (Ctrl+S), export format, Undo/Redo, Cut/Copy/Paste, Mirror (Ctrl+M), Flip (Ctrl+F), Rotate 90° (Ctrl+L / Ctrl+R), Crop (Alt+C), Resize (Alt+R), Zoom in/out/reset, Toggle background brightness (Ctrl+B), Onion skin (⇧O), Grid (Ctrl+G), Preview (Ctrl+P), Settings; right: Animations list + Animation Properties (Name, Speed, Loop, Repeat Count, Repeat To, Ping Pong); bottom: "Animation 1 Frames (1)" strip; status: zoom, pointer, size, export format.

## Event sheet (*Folha de eventos*)

Empty sheet shows the tutorial text ("This is an empty event sheet…") with an example event, `Add event` link top-left (*Adicionar evento*) and `Add…` link top-right (*Adicionar…*). Event row = margin with number · condition block `[icon Object] [condition text]` · actions column with an `Add action` placeholder (*Adicionar ação*) · per-event `Add…` link. Selected block is yellow/cream. Guest limit banner: "You have 24 events remaining".

`Add…` / empty-space context: Add event · Add function · Add custom action · Add JavaScript · Add TypeScript · Add comment · Add group · Add global variable · Include event sheet · Paste · Event sheet ▸ (*Adicionar Evento · Adicionar função · Adicionar ação personalizada · … · Adicionar comentario · Adicionar grupo · Adicionar variável global · Incluir folha de eventos · Colar*). Condition context: Edit · Add another condition · Invert · Replace condition · Replace object · Toggle · Cut · Copy · Paste · Delete · Copy as text · Event sheet ▸ (*Editar · Adicionar outra condição · Inverter · Substituir condição · Substituir objeto · Alternar · … · Copiar como texto*).

**Add condition** flow: (1) "Pick an object to create a new condition from:" (*Escolha um objeto para criar uma condição a partir dele:*) — tiles System (*Sistema*) + every object; Cancel/Help left, Next right. (2) "Add 'System' condition" — description of the highlighted item on top + search; two-column list grouped under blue category headers; recently used items highlighted; Cancel/Help left, Back/Next right. (3) "Parameters for System: Compare two values" — description, label-left fields (First value, Comparison select `= Equal to, ≠ Not equal to, < Less than, ≤ Less or equal, > Greater than, ≥ Greater or equal`, Second value); Cancel · Help · Find Expressions left, Back · Done right (*Pronto*).

System conditions by category: Angles (Is between angles, Is clockwise from, Is within angle) · General (Compare two values, Evaluate expression, Every tick, Is between values, Is group active, Is number NaN, Is value type, Object UID exists, Test regex) · Global & local variables (Compare variable, Is boolean set) · Layers (Compare opacity, Layer is empty/HTML/interactive/visible, Layer name exists) · Layout (On canvas snapshot) · Loops (For, For Each, For Each (ordered), Repeat, While) · Memory management · Pick instances (Pick all, Pick by comparison, Pick by evaluate, Pick by highest/lowest value, Pick last created, Pick nth instance, Pick overlapping point, Pick random instance) · Save & Load · Special conditions (Else, Is in preview, Trigger once while true) · Start & end (Is suspended, On end of layout, On loader layout complete, On resumed, On start of layout, On suspended) · Templates · Time (Compare time, Every X seconds, On signal).
